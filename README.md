# Kanvas Releases

Public release downloads and Sparkle update feed for **Kanvas** (macOS).

## Download

- **Latest release:** [Kanvas-0.3.24.dmg](https://raw.githubusercontent.com/einareiriksson/Kanvas-release/main/Kanvas-0.3.24.dmg) (v0.3.24)
- **Sparkle feed:** `https://raw.githubusercontent.com/einareiriksson/Kanvas-release/main/appcast.xml`

## Installation

1. Download **Kanvas-0.3.24.dmg** above and open it.
2. Drag **Kanvas.app** into **Applications**.
3. Once installed, Kanvas checks for updates automatically via **Kanvas › Check for Updates…**.

## Features

- **Scratchpad & file editor:** Tabbed notes, split view, note history, folder sidebar, and live file tailing.
- **Markdown & Mermaid:** Live side-by-side Markdown preview and offline Mermaid diagram rendering.
- **CSV / TSV table editor:** Inline cell editing, auto-detected delimiters, header row toggle, and row/column tools.
- **Code & data:** JSON and XML formatting/compacting, plus syntax highlighting for ABAP, Python, Java, and C#.
- **Clipboard history:** Searchable history for text, images, and files with pinning and quick paste.
- **iCloud sync:** Syncs notes, clipboard history, settings, and open iCloud Drive files across Mac and iOS.

## Requirements

- macOS 14.0 (Sonoma) or later
